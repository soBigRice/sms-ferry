关于送达

邮件到达与通知速度取决于运营商、网络、系统后台调度和邮箱服务商。“服务器已接收”不等于已读。当前为预览版，欢迎在 GitHub 反馈体验。

你可能想知道

支持哪些手机和邮箱？

最低 Android 8.0，主要验证设备为三星 S21 / Android 15，不代表所有机型均已实测。支持以用户名与密码、授权码或应用专用密码登录的 SMTP 服务；仅支持 OAuth 的登录方式暂不支持。接收邮箱不需要在信渡中配置 POP3 或 IMAP。

短信会经过谁的服务器？

应用直接连接你配置的 SMTP 服务，不经过作者运营的服务器。短信的来源号码、接收时间和完整正文会发送到接收邮箱，验证码不会自动隐藏；邮箱服务商和已登录邮箱的设备可能接触内容。本地加密与 TLS 不等于端到端加密。仅在自己或明确获授权的设备和邮箱上使用。

安全与隐私声明 ↗
安装后没有短信权限，怎么办？

短信读取属于 Android 受限权限，安装器和用户授权都需要允许。如果没有短信权限开关，先按仓库说明检查安装方式。三星还建议加入“从不休眠的应用”；不要为排查卸载或清除数据。
